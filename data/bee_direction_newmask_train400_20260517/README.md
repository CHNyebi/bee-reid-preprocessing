# Bee direction newmask train400 dataset

This is the current direction-classifier training dataset. It contains 400 already horizontally aligned masked bee crops generated by the new foreground-mask workflow.

Files:

- `labels.csv`: label table. The core columns are `image_path` and `label`.
- `images/`: 400 JPEG crops referenced by `labels.csv`.

Label distribution:

- `head_left`: 170
- `head_right`: 150
- `unclear`: 80

This dataset replaces the old `bee_direction_labeled_batch001_003` training data for future direction-classifier retraining.
